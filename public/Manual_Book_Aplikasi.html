# Pengantar Sistem

Sistem Manajemen Training adalah aplikasi untuk mendigitalkan dan mengotomatiskan seluruh alur pelatihan di perusahaan. Sistem ini mengatur data karyawan, pendaftaran pelatihan (Master Data), daftar hadir peserta dengan scan barcode, penginputan nilai, evaluasi CSI, hingga pencetakan Ringkasan Laporan Pelatihan PDF yang ditandatangani dan dikunci secara otomatis.

Aplikasi ini memisahkan data Master Data (Katalog standar kursus) dan Eksekusi Training (Batch / sesi yang akan diselenggarakan). Seluruh pencatatan waktu (timestamp) menggunakan zona waktu Asia/Jakarta (WIB).

1. Dashboard

Halaman / URL Kegunaan & Fitur
/admin/trainings Oversight Training: Monitoring seluruh pelaksanaan training. Kini dilengkapi dengan:
  • Extended Search Bar: Kolom pencarian yang lebih lebar untuk memudahkan input judul training yang panjang.
  • Period Filter: Dropdown filter per Bulan dan Tahun untuk mempermudah audit data berkala.
  • Smart Alerts: Seluruh pesan sukses/gagal dan konfirmasi (seperti hapus data) kini menggunakan SweetAlert2 yang lebih modern.

2. Manajemen Data Karyawan

Halaman / URL Kegunaan & Fitur
/admin/employees Daftar semua karyawan di perusahaan yang selanjutnya dapat dimasukkan sebagai peserta (trainee) dalam sebuah sesi pelatihan.
/admin/users Menu akses khusus untuk menambahkan/mengelola pengguna admin, menyetel role, dan mengunggah gambar profile / Tanda Tangan digital pengguna tersebut.

Fungsi Tombol (Button)

+ Tambah (Add)

Membuka form penambahan satu karyawan atau user secara manual.

Sync / Import Data

Menyinkronisasi data atau mengimpor karyawan dalam jumlah banyak melalui template eksternal atau database HR.

Upload Bulk Photo

Mengunggah kumpulan pas foto karyawan sekaligus berbasis ID atau NPK.

Edit Delete

Aksi pada setiap baris karyawan untuk mengoreksi data atau menghapusnya.

3. Master Data Training

Halaman / URL Kegunaan & Fitur
/admin/master-trainings Katalog standar pelatihan (contoh: K3, ISO, dsb). Di sini Anda membuat jenis kategori pelatihan baru beserta kode pelatihannya.

Fungsi Tombol (Button)

Export CSV / Import CSV

Mengunduh atau mengunggah data master template ke dalam format excel/CSV.

Execute Training

Mengubah Master (katalog) yang dipilih menjadi sebuah kelas/sesi yang siap dijalankan secara aktual.

4. Kelola Sesi & Peserta (Trainee)

Halaman / URL Kegunaan & Fitur
/admin/trainings/{id} Panel detail eksekusi kelas pelatihan. Di sini admin mengatur seluruh peserta pada batch kelas tersebut, memastikan nilai dan absensi mereka terpenuhi.
.../attendance-qr dan .../scan Layar khusus yang menampilkan QR Code untuk discan peserta, atau halaman di mana alat pemindai scanner bisa merekam barcode para karyawan (sebagai ganti mesin face-id).

Fungsi Tombol Tabel Peserta

Import CSV / Excel Template Excel

Button untuk mengunduh template kosong berisi format tabel excel, lalu mengimpornya untuk mendaftarkan banyak peserta beserta nilainya secara instan.

+ Tambah Manual

Membuka popup untuk langsung mengetik dan mencari (search) NPK/Nama karyawan guna diundang ke sesi tanpa harus import excel.

Simpan Data

Apabila Anda mengubah nilai (Pre-test, Post-test, Punctuality, dll) pada kolom input di tabel secara langsung, klik tombol ini untuk memastikan seluruh form tersimpan ke sistem.

Hadirkan Semua

Trik pintas (shortcut) untuk mengubah status seluruh peserta dari absen (merah) menjadi hadir (hijau) dalam 1 klik (centang massal).

Tombol toggle interaktif di kolom tabel. Klik satu kali untuk mengubah status masing-masing individu secara instan tanpa perlu memuat ulang halaman utama.

Suasana Pelatihan (Atmosphere)

Terletak di bawah tabel peserta, fitur ini memungkinkan admin mencatat poin-poin observasi selama pelatihan berlangsung (contoh: "Peserta sangat antusias", "AC kurang dingin").

Sync Sheets (Observasi)

Mengambil data nilai atau observasi langsung dari Google Sheets jika pelatihan menggunakan form online sebagai media input utama.

5. API Routing Reference

Endpoint Group Description & Auth Required
/api/v1/auth/* Authentication: Endpoint untuk Login, Logout, dan Refresh Token. Menggunakan Laravel Sanctum untuk pengamanan token.
/admin/trainings/search-users Unified Search API: Digunakan oleh fitur Auto-complete di seluruh dashboard untuk mencari Nama/NPK secara real-time.
/api/v1/reports/* Data Export: Endpoint khusus untuk penarikan data mentah untuk kebutuhan integrasi Dashboard PowerBI atau sistem monitoring pusat.

6. Security & Middleware

Access Control

Sistem menerapkan RBAC (Role Based Access Control). Middleware CheckRole memastikan hanya akun dengan level Super Admin atau Training Coordinator yang dapat melakukan eksekusi/penutupan (Lock) laporan.

Data Privacy

Seluruh unggahan foto karyawan dan tanda tangan digital disimpan dalam disk private. Akses ke file fisik dilindungi melalui URL bertempo (Signed URL) guna mencegah kebocoran data personal.

Semua request ke database divalidasi ketat menggunakan FormRequest & Eloquent Scoping.

7. Evaluasi CSI (Customer Satisfaction Index)

CSI digunakan peserta untuk memberikan masukan/rating terhadap kelas pelatihan dan Instruktur (Trainer). Fitur ini berlokasi persis di bawah tabel peserta.

Aksi (Tombol Khusus)

Manual Input CSI

Jika Anda tidak memiliki CSV tapi hanya memiliki kertas angka. Anda bisa mengklik tombol ini untuk memunculkan modal (form manual) dan mendaftarkan total skor untuk pertanyaan CSI.

Sync Google Sheets CSI

Otomatisasi penarikan data rating CSI dari Google Forms yang telah diintegrasikan dengan spreadsheet pusat.

8. Summary Laporan & Validasi/Lock Report

Halaman / URL Kegunaan & Fitur
.../summary & .../attendance-list Report Center: Cetakan resmi kertas A3 (Summary) dan A4 (Daftar Hadir).
  • Attendance List: Menggunakan format tabel horizontal standar (3 kolom: No, Nama, Tanda Tangan).
  • Interactive Photo: Kolom tanda tangan mendukung Input Foto Langsung (klik area TTD untuk upload foto Trainer/PIC jika belum ada di sistem).

Tombol Lock Report

Cekatan & Eksekutif (Klik Kunci)
Saat di klik, seluruh pelatihan ini akan di verifikasi ("Approved / Locked"). Setelah dikunci:

  • Laporan akan terkunci secara resmi (Batch Execution Finisihed).
  • Seluruh Input (Kehadiran & Nilai di dashboard) Disable.
  • Kolom tanda tangan terkunci mati.

Kolom Penandatangan

Di menu bawah summary, nama-nama penandatangan (Prepared, Checked, Confirmed) bersifat interaktif.

  • Ketik Langsung: Jika diketikkan nama User, tanda tangan digital profil miliknya tersematkan otomatis.
  • Update Foto (Hover): Arahkan kursor ke area gambar untuk memunculkan tombol Update, berguna jika yang bersangkutan bukan User (eksternal / manual upload).
