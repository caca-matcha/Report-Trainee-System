1. Stack Teknologi & Versi

Report Trainee System menggunakan ekosistem Laravel terkini untuk menjamin stabilitas data peserta dan efisiensi pelaporan.

Komponen Teknologi Versi Kebutuhan
Frontend Blade + Alpine.js ^12.0.0 Manipulasi DOM ringan & reactivity side-sidebar.
Backend Laravel Framework ^12.0.0 Core system untuk handling business logic & master data.
CSS Framework Tailwind CSS ^3.4.0 Styling premium & responsivitas dashboard.
Database MySQL / MariaDB 8.0+ Pencatatan ribuan data peserta dan histori training.

6. Security & Middleware

Akses Kontrol (RBAC)

Sistem menggunakan middleware role:admin untuk membatasi akses ke menu master data. Terdapat protokol npk_restrict untuk memastikan user hanya dapat mengakses data personifikasi masing-masing.

Data Integrity

Setiap input form dilindungi oleh CSRF Protection berbasis session token. Database memanfaatkan Unique Constrain pada kolom NPK untuk mencegah duplikasi subjek karyawan.

7. Deployment Guidelines

1

Jalankan php artisan optimize setelah mengunggah perubahan file ke server produksi untuk menyegarkan cache route & config.

2

Pastikan direktori storage/ dan bootstrap/cache/ memiliki izin tulis (writeable) bagi user server web.

3

Inisialisasi link penyimpanan media dengan perintah php artisan storage:link agar aset foto peserta dapat diakses publik.
