01

Hak Akses & Dashboard

Sistem RTS memisahkan akses Dashboard berdasarkan peran pengguna. Hanya pengguna dengan mandat role:admin yang memiliki kendali penuh.

Statistik Dashboard Utama

  • Ongoing: Sesi pelatihan yang sedang berjalan hari ini.
  • Upcoming: Sesi yang dijadwalkan di masa mendatang.
  • Archive: Histori laporan pelatihan yang sudah disetujui.

Aktivitas Terkini

Bagian bawah Dashboard menyajikan "Live Feed" aktivitas entry data terbaru, memudahkan Admin untuk melompat langsung ke sesi yang paling aktif.

02

Manajemen Katalog Master Program

Master Data berfungsi sebagai "Template" untuk setiap program pelatihan agar identitas kode dan topik tetap konsisten.

Metode Penginputan

Admin dapat mengunggah file **CSV/Excel** untuk mendaftarkan ratusan program sekaligus melalui panel Import. Sistem akan memvalidasi duplikasi Event No secara otomatis untuk mencegah tumpang tindih data.

Parameter Standar

Setiap Master menyimpan standar Passing Grade, estimasi durasi, dan kategori (Mandatory/Managerial/Technical). Parameter ini akan diwariskan ke setiap Batch Training yang dibuat.

03

Eksekusi Batch & Penjadwalan

Langkah Eksekusi Training

1

Pilih program dari menu Master Training dan klik tombol EXECUTE.

2

Tentukan Periode (Mulai & Selesai), Lokasi Pelatihan, serta daftar PIC & Trainer penanggung jawab.

3

Sistem akan otomatis men-generate **Unique Training Code** (Contoh: MDT_2026_01) berdasarkan sekuensial sistem.

04

Monitoring & Presensi QR

Lupakan absensi manual kertas. RTS menggunakan teknologi QR Code dinamis untuk validasi kehadiran fisik.

Live Presence QR

Setiap Batch memiliki menu **Attendance QR**. Admin dapat menampilkan ini di layar proyektor ruang kelas untuk di-scan oleh peserta yang hadir.

Photo Verification

Peserta wajib mengambil foto wajah saat proses scan untuk memastikan validitas presensi sesuai dengan NPK karyawan yang terdaftar.

05

Manajemen Nilai & Evaluasi

Aspek Penilaian Metode Pengisian
Skor Akademik (Pre/Post Test) Gunakan fitur Import Participant CSV untuk mengisikan nilai secara massal dari lembar koreksi ujian.
Evaluasi & Atmosfer (CSI) Input rata-rata skor kepuasan peserta (Skala 1-4) dan suasana pelatihan untuk kalkulasi indeks kepuasan program.
Observasi Skill (Gap Analysis) Sinkronisasikan data hasil observasi lapangan via Google Sheets URL jika diperlukan integrasi data eksternal.
06

Summary Report & Approval

Finalisasi laporan adalah langkah krusial untuk mencatat "Sertifikasi" resmi ke dalam track record karyawan.

Setelah data nilai dan foto lengkap, klik tombol Approve Training di panel detail. Sistem akan secara otomatis:

  • Membubuhkan **APPROVED STAMP** digital.
  • Mengunci data report (Read-only) untuk integritas audit.
  • Memasukkan status training ke dalam riwayat **Archive**.
07

Administrasi User & Karyawan

Bulk Employee Import

Sinkronisasi data karyawan secara massal untuk mengakomodasi Trainee baru atau perubahan jabatan/departemen dari sistem SDM pusat.

Tips: Gunakan penamaan file Foto NPK.JPG untuk Bulk Import Foto.
