1 Pendahuluan

Dokumen ini disusun sebagai panduan Technical Handover untuk pengembang (developer) yang akan melanjutkan, memelihara, atau menambah fitur di dalam aplikasi Report Trainee System. Dokumen ini merangkum arsitektur, teknologi, serta aliran proses bisnis yang telah diimplementasikan, guna mempercepat proses adaptasi (onboarding) tim IT yang baru di PT Dharma Polimetal Tbk.

2 Teknologi & Stack

Aplikasi ini berjalan menggunakan stack teknologi modern terstandarisasi:

  • Backend PHP ^8.2 & Framework Laravel 12
  • Frontend CSS Tailwind CSS v3 (Compiled via Vite)
  • UI Interaktif Alpine.js & Blade Components
  • Database MySQL / MariaDB

3 Arsitektur & Struktur Direktori

Sistem mengikuti struktur standar Laravel 12 untuk memudahkan skalabilitas dan kolaborasi tim:

app/Http/Controllers/ Menampung seluruh logika bisnis aplikasi.
app/Models/ Definisi entitas database dengan Eloquent ORM.
resources/views/ Folder template tampilan (Blade Engine).

4 Struktur Database & Entitas

Pilar utama data dalam aplikasi ini meliputi:

1. Master Training

Template data program pelatihan statis (MDT, ARS, TKT, MNG, dsb).

2. Training (Batch)

Varian pelaksanaan training dari Master yang mencakup jadwal dan lokasi.

3. Training Participant

Data traker kehadiran, skor pre-test/post-test, dan sertifikasi.

5 Alur Bisnis Proses (Workflow)

  1. 01.
    Definisi Master

    Mendaftarkan program pelatihan ke database pusat.

  2. 02.
    Eksekusi Batch

    Administrasi membuat sesi latihan aktif dari Master Training.

  3. 03.
    Presensi QR

    Trainee melakukan scan QR di lokasi pelatihan untuk kehadiran.

  4. 04.
    Pelaporan

    Sistem mengalkulasi skor dan menghasilkan Summary Report.

6 Panduan Instalasi 

# Install backend dependencies
composer install

# Environment setup
cp .env.example .env
php artisan key:generate

# Database migration
php artisan migrate --seed

# Frontend dependencies
npm install && npm run build

7 Pengujian (Testing)

Sistem menggunakan PHPUnit / Pest untuk validasi fitur. Standar penulisan diwajibkan melewati pengecekan Linter:

php artisan test

8 Maintenance & Troubleshooting

Vite Manifest: Jalankan npm run build jika layar blank pada sistem production.

Clear Cache: Gunakan php artisan optimize:clear jika routing gagal dimuat.
