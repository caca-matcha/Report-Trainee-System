1. Akses & Tinjauan Dashboard

Akses ke portal Admin Control ini dibatasi dan hanya diberikan kepada staff yang terdaftar dengan hak role:she. Portal ini dirancang untuk pemantauan seluruh insiden keselamatan dari *bird-eye view*.

Sistem Multi-Role: Saat Anda login ke portal umum SIDUBA, sistem secara otomatis mengalihkan Anda ke panel Administrasi SHE jika profil Anda memiliki mandat tersebut tanpa perlu mengakses URL khusus yang merepotkan.

Seksi Need Follow-up: Tepat di layar Dashboard, tersaji antrian laporan bahaya berstatus Menunggu Validasi yang menuntut aksi eksekusi secepatnya.

Notifikasi Real-time: Amati ikon Lonceng di pojok kanan atas untuk memantau tiket bahaya seketika (*real-time alerting*) sesaat setelah submit dilakukan oleh karyawan tanpa repot memuat ulang halaman browser.

2. Setup Peta & Resolusi Grid (Map Editor)

Modul interaktif Map Planner ini berfungsi sebagai kanvas area penempatan titik masalah kerawanan pabrik/aset dan merupakan ruh utama pendataan duga bahaya berbasis koordinat visual.

Unggah Denah & Tetapkan Visual Utama

Masuk ke menu Peta Bahaya (Maps). Tambahkan master data denah pabrik Anda (Unggah JPG berkualitas baik). Centang sebagai Primary Map agar peta layout tersebut menjadi landasan kanvas default ketika operator akan melapor.

Grid Boundaries Mapping

Setiap peta memiliki tombol Admin Editor Grid. Tarik tetikus (mouse drag) membentuk petak Grid di area Peta visual menambahkan *cell* batas area mana saja yang terbuka untuk diseleksi oleh Karyawan dalam melapor kejanggalan.

3. Manajemen Master Lokasi

Menyusun kamus lokasi (Misal: Area 1, Panel Listrik Barat) yang ter-asosiasikan dengan struktur Peta (Master Map).

Tindakan Admin Cara Melakukan
Menyuntikkan Lokasi Masif (Excel) Unduh kerangka file pada tombol Download Template. Isi lembar Excel tersebut berdasarkan data hierarki, lalu pilih Import ke sistem dan tunggu SIDUBA me-resolusi massal data Anda.
Visual Sort (Sortir Dinamis Lokasi) Akses panel daftar Lokasi. Tahan dan geser lambang urutan (Garis susun Drag & Drop) pada list tabel baris per baris. Nomor susunan akan terekam ke sistem database tanpa harus melakukan modifikasi form id angka ganda.

4. Siklus Validasi Duga Bahaya

Admin SHE bertindak sebagai pemegang keputusan (Approval Gate) terhadap kebenaran ancaman yang dipaparkan Pelapor.

Tiket "Menunggu Validasi"

Admin akan mereview deskripsi kerawanan yang digabungkan bersama foto *Real-evidence* Pelapor. Dalam layar detail, Anda harus mengeliminasi *hoax* (Tolak dengan menyisipkan Pesan Alasan via prompt komentar) atau Mensahkan insiden temuan menjadi Antrian **Diproses** dengan merumuskan arahan mitigasi pertama.

Penyelesaian Instan (Bypass)

Selain melanjutkan ke proses tunggu delegasi mekanik, tiket yang tergolong Ringan (Misal: pelapor membersihkan tumpahan oli langsung lalu melaporkan histori) dapat langsung diselesaikan status menjadi **Ditutup/Selesai** saat diverifikasi.

5. Mendelegasikan Tugas (Tunjuk PIC Lapangan)

Pelimpahan Anggota Penanggung Jawab (PIC)
Saat sebuah entri bahaya memenangkan sah verifikasi mitigasi di langkah ke 4, Formulir "Lanjutkan Tindakan" akan mewajibkan Tim Admin (SHE) menunjuk satu PIC dari rentang list Master Karyawan.

Contoh skenario: Melimpahkan perbaikan atap pabrik bocor kepada Karyawan Tim Listrik lewat drop-down Select yang sudah difilter oleh AJAX Live-Search. Pekerja PIC terasosiasi akan diperlihatkan laporan yang ditugaskan ke dalam Panel Pribadi mereka.

Cek Evaluasi (*After* Action):
Anggota PIC kelak memutakhirkan insiden menyertakan foto *Terselesaikan/Perbaikan (After)*. Status bahaya berubah menjadi `Selesai` dan log bukti pemulihan aman dicatat.

6. Export Company Data Format Excel

Menyusun Berkas Berita Acara untuk Manajemen Bulanan dari data raw pangkalan Duga Bahaya.

Panduan Export Excel Data History:

  • Tuju Menu Laporan, cari opsi Export Excel Bulk. Tombol ini dipadukan dengan kompresor library Excel native agar menghasilkan satu bundle Worksheet. Worksheet memuat Metadata Komprehensif insiden seperti: NIK Pelapor, Timestamp Bukti, Tingkat Durasi hingga Komentar Tutup Audit.

7. Administrasi Pengurus Sistem (Users/Employees)

Tugas Teknis Panel User

Pengelola (SHE/Admin Database) sewaktu-waktu harus menambahkan akun karyawan magang musiman untuk melapor. Modul "User Management" telah siap menuntun tugas rutin seperti merevisi Departemen atau me-Reset Kata sandi default akun staff yang terkunci.

Tip: Upload Database XLS untuk Onboarding serentak Karyawan lebih gesit tanpa Input manual Form satu-persatu.
